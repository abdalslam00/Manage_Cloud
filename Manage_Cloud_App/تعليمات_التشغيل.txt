# Manage Cloud - دليل التشغيل السريع

هذه نسخة تنفيذية جاهزة للتشغيل من تطبيق إدارة قواعد بيانات MySQL عبر نفق SSH.

## متطلبات التشغيل:
- نظام تشغيل Windows (64-bit).
- لا يلزم تثبيت بايثون لتشغيل `main.exe`.

## كيفية الاستخدام:
1. قم بتشغيل البرنامج عبر النقر المزدوج على `main.exe`.
2. عند الفتح لأول مرة، ستظهر نافذة "Connection Settings":
   - قم بإدخال بيانات خادم SSH (IP، المستخدم، كلمة المرور).
   - قم بإدخال بيانات قاعدة بيانات MySQL (اسم المستخدم، كلمة المرور، اسم قاعدة البيانات).
3. اضغط "Connect" للاتصال وحفظ الإعدادات تلقائياً في ملف `.env`.
4. يمكنك أيضاً تعديل ملف `.env` يدوياً لحفظ الإعدادات مسبقاً.
